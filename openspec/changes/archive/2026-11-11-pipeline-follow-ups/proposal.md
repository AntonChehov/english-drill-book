# Proposal

## Why

The first run of the whole process, from proposal to merge, showed three places where the pipeline built by `bootstrap-app-and-ci` does not yet fit the process it enforces:

- Step 8 of `docs/process.md` archives a merged change by pull request, but the evidence check (C-18) rejects any pull request that does not name an active change. A change can therefore never be archived through the protected `main`.
- release-please proposes `1.0.0` as the first release, for an app that has a placeholder screen.
- Task 7.4 of the bootstrap — the evidence check failing on a real pull request without a review record, and with an unresolved finding — was only shown by unit tests, because its own pull request already carried a complete record.

## What Changes

- The evidence check exempts the **archive pull request**: opened by the bot from an `archive/` branch and changing nothing but OpenSpec files and the roadmap. Every other pull request is judged as before.
- The first release is `0.1.0`; versions stay below `1.0.0` until the owner decides otherwise.
- The refusals of task 7.4 are shown on this change's own pull request, in the order they naturally occur: opened before the review record exists, then with a finding left without an outcome, then complete.
- `bootstrap-app-and-ci` is closed: its remaining tasks are ticked with their evidence, branch protection is recorded as switched on, and the change is archived, which creates `openspec/specs/app-shell`.

Requirements delivered from `docs/product/`: none. This change alters no behaviour of the app, so it has no delta specs (`skip_specs`).

Left for later: nothing of this kind is known. The next change is slice 1.2 of the roadmap.

## Capabilities

None.

## Impact

- `scripts/pr-evidence.mjs` and its tests; `release-please-config.json`.
- Owner-controlled documents, changed by this change with the owner's approval: `docs/process.md` (step 8), `docs/constitution.md` (C-14 and C-18 name the two exempt pull requests), `docs/roadmap.md`.
- `openspec/specs/app-shell/` appears; `openspec/changes/bootstrap-app-and-ci/` moves to the archive.
- External: the open release pull request is regenerated by release-please with the new version after the merge.
